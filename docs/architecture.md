# Architecture｜分层架构与设计决策

## 分层视图

```
┌─────────────────────────────────────────────────────────┐
│ 交互层   DSH web/TUI/headless · 学员直接跑 examples CLI   │
├─────────────────────────────────────────────────────────┤
│ Preset 层  research-lab / edu-research / health-research │
│            （agent.cordis.yml：守则 + skills + tools 清单）│
├─────────────────────────────────────────────────────────┤
│ Skill 层   8 通用 + 4 领域（适用条件/契约/流程/验证/失败）  │
├─────────────────────────────────────────────────────────┤
│ Tool 层    data_audit · regression · classification      │
│            report_builder —— stdout-only-JSON 计算层      │
├─────────────────────────────────────────────────────────┤
│ 知识/数据层 domains/*(domain.yml+knowledge+protocols)     │
│            datasets/*(raw只读+字典+协议+expected锚点)      │
├─────────────────────────────────────────────────────────┤
│ 验证层   verify.py：SHA256 → 确定性复跑 → 双实现交叉 → 断言 │
└─────────────────────────────────────────────────────────┘
```

## 设计决策（为什么这样建）

1. **先有真闭环再有界面**：管线、产物、验收先于任何 UI；界面只是壳。
2. **计算与解释分离**：语言模型只做调度与解读；一切数字出自 tools/ 的真实
   执行（stdout-only-JSON 契约）。"模型生成 p 值"在本框架中是定义错误。
3. **协议先于数据**：research-design 产 protocol.md，分析计划锁定后不得
   静默更改——这是科研可复现的最低配置。
4. **双实现互证**：头条指标必有第二条独立路径（numpy-OLS vs statsmodels；
   秩和 AUC vs sklearn），verify 强制对账。容差分级：确定性复跑 1e-6；
   同概率双口径 1e-9；跨求解器 5e-3。
5. **锚点即教材**：expected/ 里的每个数字（0.263/0.850/0.950/0.094…）
   同时是回归测试基准与课堂讲述的事实锚点——教材与测试用同一份真相。
6. **领域即配置**：新学科=domain.yml+协议+字典+Skill 四件，tools 与验收
   设施零改动；"换数据仍能跑"是框架级验收项。
7. **失败是功能**：缺列、坏编码、SHA256 不匹配都走"结构化错误+修正要求"，
   拒绝编造是 Skill 层显式条款。

## 与 DSH 的关系

DSH（DeepSeek Harness）提供模型路由、工具调用、会话与 profile 设施；本仓库
不重写运行时，只交付 Preset/Skill/Tool/数据/协议/验收。兼容基线 0.2.1-rc.2，
升级先跑 verify + dump-config 冒烟。

## 已知边界（诚实声明）

- R 接口未实现（路线图）；NHANES 类复杂抽样需权重/分层/聚类支持，不在
  当前工具层能力内；
- CV 折切分依赖 sklearn 实现，参考口径只锁定留出集 AUC 与系数符号；
- Windows 安装脚本按 PowerShell 5.1+ 编写，CI 覆盖 windows-latest 矩阵。
