# evidence-traceability｜证据溯源技能

## 适用条件

全程可用；在报告定稿与对外分享前必须执行一次完整核查。

## 工作步骤

1. **数据链**：每个数据集核对 metadata/source.yml（URL/作者/年份/许可/SHA256/
   访问日期）；raw 文件哈希复算与声明一致；
2. **结论链**：报告中的每个数字 → results.json 字段 → 生成它的命令 → 代码
   commit（版本号）四级溯源表；
3. **知识链**：领域知识文件（domains/*/knowledge/）逐条登记来源与性质
   （教科书结论/文献结论/本项目实测），混用即降级标注；
4. **许可链**：CC BY 4.0 数据的引用三要素（作者/标题/来源）在报告与
   THIRD_PARTY_NOTICES.md 双落点核对；
5. **反幻觉核查**：语言模型引用的任何"文献结论"若无登记来源，一律标记为
   未验证并要求补充，禁止直接写入报告。

## 输出

- 证据链核对表（数据/结论/知识/许可四段）
- 未验证项清单（必须清零或显式保留并标注）

## 验证条件

- 抽查任一数字，四级链路 60 秒内可人工走通；
- 数据 SHA256 全部匹配。

## 失败处理

- 链路断点（如 results.json 被手改）→ 触发 verify.py 重跑重建，禁止手补数字。
