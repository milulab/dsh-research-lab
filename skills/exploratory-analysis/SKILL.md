# exploratory-analysis｜探索性分析技能

## 适用条件

数据通过质量审计后，正式建模前的结构认识阶段。也可独立用于课堂演示
"从数据能直接看到什么"。

## 输入契约

- 质量审计通过的 DataFrame/CSV + 变量角色表
- 本技能只读数据、只产出描述性结果，不做任何推断结论

## 工作步骤

1. **单变量概览**：数值列（n/均值/SD/四分位/IQR 异常数）+ 类别列（频次表），
   直接调用 `tools/data_audit.py` 的列级输出，不重复造轮子；
2. **结果变量分布**：outcome 的直方图/条形图（G3 分布、心脏病 160/137 阳性比），
   matplotlib Agg 后端落盘 PNG，返回路径；
3. **分组比较预览**：按暴露变量分组（studytime 4 组的 G3 均值与箱线图；
   cp 类型的年龄分布），为后续推断选择提供视觉证据；
4. **两两关联矩阵**：数值变量 Pearson/Spearman 矩阵热图，标注方向与强度；
5. **书写纪律**：每张图/每个表配一句"这显示了什么"，**禁止**出现
   "证明/导致/效应"字样——探索阶段只有"显示/提示/一致/不一致"。

## 输出

- `outputs/figures/` 图表 PNG（Agg 后端，零交互依赖）
- 描述统计表 CSV
- 探索笔记（每图一句结论 + 对正式分析的提示，如"残差异方差迹象→M1 需 HC3 敏感性"）

## 验证条件

- 所有图表有轴标签与标题；所有表有 n；
- 结论措辞不含因果词。

## 失败处理

- 图表后端不可用 → 返回结构化错误与已完成的表数据，不中断整个分析；
- 分组样本过小（<10）→ 图上标注"样本量不足，仅示意"。
