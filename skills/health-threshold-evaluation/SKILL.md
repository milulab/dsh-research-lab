# health-threshold-evaluation｜阈值评价领域技能

## 适用条件

已训练的二分类模型（H2–H4 产出），需要讨论"多少分算阳性"时。

## 核心教义

1. **阈值是决策，不是统计**：0.5 没有天然正当性；阈值选择取决于漏诊（FN）
   与误报（FP）的相对代价——本数据 0.5 阈值下敏感度 0.786，意味着约 21%
   阳性被漏掉，这在筛查语境通常不可接受；
2. **Youden 是参考不是答案**：本模型 Youden 阈值 0.186 → 敏感度 1.00 /
   特异度 0.781——把 FN 压到 0 的代价是 FP 从 4 升到 7（60 例测试集）；
   教学上必须同时呈现代价变化；
3. **扫描表呈现全貌**：19 档（0.05–0.95）阈值扫描，课堂用滑块或表格让学员
   直观看到敏感度-特异度此消彼长；
4. **判别与校准分离**：AUC 只说"排序对不对"（0.950）；Brier=0.094 + 校准曲线
   说"概率本身可信吗"；筛查场景常只需排序，决策场景两者都要。

## 工作步骤

1. 从 results.json 取阈值扫描表，生成权衡图（敏感度/特异度 vs 阈值）；
2. 给定一个应用语境（筛查/确诊辅助），让学员选阈值并说出代价依据；
3. 输出：阈值建议表（语境→阈值→预期混淆矩阵→代价陈述），附不确定度提示
   （测试集 60 例，指标有抽样波动）。

## 验证条件

- 任何阈值建议必须带混淆矩阵与代价陈述；
- 不出现"最优阈值"的无语境表述（Youden 只是最大约登指数参考点）。

## 失败处理

- 学员要求"找到最好的阈值" → 转为代价讨论：给出代价比参数化选择
  （如 FN 代价:FP 代价 = 5:1 时阈值 X），拒绝无语境的"最优"。
