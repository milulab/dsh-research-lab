# model-validation｜模型验证技能

## 适用条件

统计建模产出结果之后、对外报告之前。本技能是"结论能不能出门"的最后一道关。

## 验证清单（顺序执行）

1. **泄漏审计**：
   - 教育场景锚点：M1（不含 G1/G2，调整 R²=0.263）回答"行为-成绩关联"；
     M2（含期中成绩，调整 R²=0.850）回答的是"期末解释"——把 M2 当预测改进
     是典型的目标信息泄漏误读，必须显式区分；
   - 建模场景锚点：标准化/编码只在训练折内（Pipeline）；CV AUC（0.869）与
     留出集 AUC（0.950）分开报告，禁止只报好看的那个。
2. **诊断解读**：BP/JB/VIF/残差图逐项给出"是否满足前提+影响什么结论"，
   异方差→HC3 稳健 SE 敏感性；残差非正态→大样本下推断稳健性说明。
3. **不确定性陈述**：每个头条指标带不确定度（CV 标准差；小测试集 n=60 必须提示
   抽样波动）；禁止把点估计当精确值引用。
4. **独立复核**：对报告中最关键的一个数字，用第二条实现路径复算
   （教育：numpy-OLS vs statsmodels，逐位一致；健康：秩和 AUC vs sklearn，
   同概率差 <1e-9，跨求解器容差 0.005）。不一致→停下报告差异，禁止择优。
5. **复现校验**：`python scripts/verify.py --suite <edu|health>` 全绿后才允许交付；
   提交包必须附 SHA256、seed、依赖版本。

## 输出

- 验证记录（清单逐项勾稽，含复核数字对）
- 校验命令输出（原样粘贴）

## 验证条件

- 清单 5 项全部通过；任何一项不过，报告只能标记为 draft。

## 失败处理

- 复核不一致且无法解释 → 结论撤回，转为"差异调查报告"；
- 复现失败 → 检查环境版本（requirements.txt 锁定范围），报告差异矩阵。
